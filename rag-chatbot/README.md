# AI RAG Chatbot using Endee Vector Database

## Project Overview

This project demonstrates a simple AI based semantic search
system using Endee vector database.

The system stores text as vectors and retrieves the most
similar results based on user query.

## Problem Statement

Normal search works using keywords.
This project implements semantic search using vector database.

## Technology Used

- Python
- Endee Vector Database
- Semantic Search
- RAG (Retrieval Augmented Generation)
- GitHub

## How Endee is Used

Endee is used as vector database to store documents.
User query is converted into vector.
Nearest vectors are searched using Endee.
